# 数独游戏

一个基于Pygame开发的数独游戏，支持实时关卡生成、计时、错误提示等功能。

## 项目结构

```
main/
├── kernel/
│   ├── sudoku_validator.py    # 数独校验器，负责验证数独的合法性
│   ├── sudoku_generator.py    # 数独生成器，负责自动生成数独关卡
│   ├── game_controller.py     # 游戏控制器，负责管理游戏状态和操作
│   └── utils.py                # 工具类，提供常用的工具函数和UI绘制
├── main.py                     # 游戏主入口文件
├── requirements.txt            # 项目依赖文件
└── README.md                   # 项目说明文档
```

## 功能特性

1. **实时关卡生成**：每次开始新游戏都会生成一个新的数独关卡，保证每次游玩体验不同。
2. **计时功能**：记录每个关卡的完成时间。
3. **关卡计数**：统计玩家完成的关卡数量。
4. **错误提示**：填写不符合规则的数字时，单元格会标红显示。
5. **答案显示**：点击"答案"按钮可以显示当前关卡的完整答案。
6. **键盘鼠标控制**：支持鼠标点击选择单元格，键盘输入数字。

## 技术要求

- Python 3.9+
- Pygame 2.0+

## 安装依赖

在运行游戏之前，需要先安装项目依赖：

```bash
pip install -r requirements.txt
```

或者直接安装Pygame：

```bash
pip install pygame
```

## 运行游戏

进入main目录，运行main.py文件：

```bash
cd main
python main.py
```

## 游戏操作

### 鼠标操作
- **点击单元格**：选择要填写的单元格
- **点击"新游戏"按钮**：开始一个新的关卡
- **点击"完成"按钮**：检查当前关卡是否完成正确
- **点击"答案"按钮**：显示当前关卡的完整答案（显示答案后，"完成"按钮会变成"重新开始"按钮）

### 键盘操作
- **数字键 1-9**：在选中的单元格中输入对应数字
- **小键盘数字键 1-9**：在选中的单元格中输入对应数字
- **退格键/删除键**：清除选中单元格中的数字
- **方向键（↑↓←→）**：在单元格之间移动选择

## 核心模块说明

### 1. SudokuValidator（数独校验器）
- `is_valid_board()`：检查整个数独棋盘是否有效
- `is_valid_row()`：检查一行是否有效
- `is_valid_column()`：检查一列是否有效
- `is_valid_box()`：检查一个3x3小九宫格是否有效
- `is_valid_move()`：检查在指定位置放置数字是否有效
- `is_board_complete()`：检查棋盘是否完全填满
- `validate_board()`：验证棋盘并返回详细错误信息

### 2. SudokuGenerator（数独生成器）
- `generate_board()`：生成一个完整的数独棋盘（包含解决方案和谜题）
- `_fill_board()`：使用回溯算法填充完整的数独棋盘
- `_remove_numbers()`：从棋盘上移除指定数量的数字
- `_has_unique_solution()`：检查当前棋盘是否有唯一解
- `solve_board()`：求解数独棋盘
- `generate_puzzle_with_solution()`：生成一个数独谜题及其解决方案

### 3. GameController（游戏控制器）
- `start_new_game()`：开始新游戏
- `restart_level()`：重新开始当前关卡
- `select_cell()`：选择单元格
- `input_number()`：输入数字到当前选中的单元格
- `check_completion()`：检查玩家是否完成了数独
- `show_answer()`：显示答案
- `get_elapsed_time()`：获取已用时间
- `get_formatted_time()`：获取格式化的时间
- `is_cell_initial()`：检查单元格是否是初始给定的数字
- `is_cell_error()`：检查单元格是否有错误
- `get_current_level()`：获取当前关卡数

### 4. Utils（工具类）
- `get_chinese_font()`：获取支持中文的字体
- `draw_text()`：在表面上绘制文本
- `draw_button()`：绘制按钮
- `is_mouse_over()`：检查鼠标是否在指定区域内
- `format_time()`：格式化时间
- `create_empty_board()`：创建空的数独棋盘
- `copy_board()`：复制数独棋盘
- `is_valid_position()`：检查位置是否在数独棋盘范围内
- `get_box_index()`：获取单元格所在的3x3小九宫格索引

## 数独规则

数独是一种在9×9网格中填入数字1至9，使得每行、每列及每个3×3小九宫格内数字均不重复的逻辑推理游戏。

具体规则：
1. 每行的9个单元格中填入1-9的数字，不重复
2. 每列的9个单元格中填入1-9的数字，不重复
3. 每个3×3小九宫格的9个单元格中填入1-9的数字，不重复

## 注意事项

1. 游戏会自动尝试使用系统中的中文字体，如果找不到合适的中文字体，会使用默认字体。
2. 初始给定的数字单元格不可修改，玩家只能在空白单元格中填写数字。
3. 填写错误的数字会标红显示，但不会阻止继续游戏，玩家可以随时修改。
4. 点击"答案"按钮后，当前关卡的答案会显示出来，但此时无法继续游戏，需要点击"重新开始"按钮重新开始当前关卡。
